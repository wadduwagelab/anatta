# Dataset provenance and licenses

Everything the harness consumes lives under `data/`. This file records where
each piece came from, its license, and whether it is tracked in this repo.
Rule applied: datasets are vendored only where the upstream license clearly
permits redistribution; otherwise the repo ships a download script instead.

| Path | Source | License | In repo? |
|---|---|---|---|
| `data/falseqa/*.csv` | [FalseQA](https://github.com/thunlp/FalseQA) (Hu et al., [ACL 2023](https://aclanthology.org/2023.acl-long.309/)) | **None published** upstream | **No** — fetch with `scripts/download_data.py` |
| `data/mmlu_pro/subset.json` | [TIGER-Lab/MMLU-Pro](https://huggingface.co/datasets/TIGER-Lab/MMLU-Pro) (Wang et al., NeurIPS 2024 D&B) | MIT (per the HF dataset card) | Yes (fixed 200-question slice of the test split) |
| `data/sycon/questions.txt`, `data/sycon/arguments.txt` | [SYCON-Bench](https://github.com/JiseungHong/SYCON-Bench) debate-setting topics (Hong et al., Findings of EMNLP 2025) | MIT (upstream `LICENSE`) | Yes |
| `data/probes/self_report.jsonl` | Original to this project (generated by `scripts/gen_self_report_probes.py`) | MIT (repo license) | Yes |
| `data/probes/shutdown.json` | Original to this project (20 hand-written scenarios) | MIT (repo license) | Yes |
| `data/probes/self_knowledge.json` | Original to this project (22 hand-written MCQs in the style of SAD "facts") | MIT (repo license) | Yes |
| `data/_vendor/` | Raw upstream checkouts (FalseQA-main, SYCON-Bench-master; ~400 MB) | Upstream terms | **No** — regenerable, gitignored |

## FalseQA (not redistributed)

The FalseQA repository publishes the dataset but carries **no license file or
license statement**, which by default means no redistribution right. We
therefore do not track `data/falseqa/` in git. To fetch it:

```bash
python3 scripts/download_data.py
```

The script downloads `train.csv` / `valid.csv` / `test.csv` directly from the
upstream GitHub repo (or reuses `data/_vendor/FalseQA-main/` if you cloned it)
and verifies row counts. The premise benchmark (`--benchmarks premise`) and the
full mock smoke run need these files; everything else runs without them.

If the upstream repo ever adds a license permitting redistribution, the CSVs
(564 KB) can simply be committed.

## MMLU-Pro subset

`scripts/download_data.py` also (re)builds `data/mmlu_pro/subset.json` — the
first 200 rows of the MMLU-Pro test split via the Hugging Face
datasets-server API, keeping `question`, `options`, `answer`, `answer_index`,
`category`. The slice is deterministic (offset 0, fixed order), so the tracked
file is reproducible. Sycophancy items sample from the first half of this
subset and the capability control from the second half, so they never overlap.

## SYCON-Bench topics

Only the two small debate-setting text files are vendored (MIT). The rest of
the upstream repo (other settings, model outputs) is not needed; the
sycophancy runner implements its own pressure protocol over MMLU-Pro items and
uses SYCON-Bench's turn-of-flip / number-of-flips metrics, not its data.

## Also excluded from the public artifact (copyright)

- `_ref/` — PDF of Walpola Rahula, *What the Buddha Taught* (Grove Press).
  Cited in the paper as `rahula1974what`; obtain the book itself.
- `paper/papers/` — downloaded PDFs of cited papers. Every citation in
  `paper/references.bib` and `paper/related_work_survey.md` carries a DOI or a
  verification URL, so nothing depends on these local copies.
- `paper/neurips_2025.sty` — the NeurIPS style file is distributed for authors
  without an explicit redistribution license. `paper/main.tex` compiles
  without it (falls back to the `article` class); to reproduce the NeurIPS
  layout, download the style file from the NeurIPS website and drop it next to
  `main.tex`.
